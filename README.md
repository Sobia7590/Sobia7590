# Sobia Arshad

M.Sc. AI in Healthcare candidate at Inje University, South Korea (GKS Scholar). I build and rigorously evaluate machine learning models for neuroimaging, medical image grading, and clinical prediction — with more attention to correct methodology (censoring bias, multiple-comparison correction, proper cross-validation) than to headline numbers.

## Research focus
- Multimodal ML for neurodegenerative disease prediction (ADNI)
- Attention-based deep learning for medical image grading
- LLM agents for clinical report generation

## Publication
**LGA-Net: Cross-Dataset Mask-Supervised Attention for Diabetic Retinopathy Grading**
Accepted at MICAD 2026 (7th International Conference on Medical Imaging and Computer-Aided Diagnosis), Edinburgh, UK, October 2026.

## Featured projects

| Project | What it does |
|---|---|
| [adni-mci-ad-prediction](https://github.com/Sobia7590/adni-mci-ad-prediction) | Censoring-safe, multimodal MCI-to-AD conversion prediction on ADNI (n=473), with bootstrap CIs and multiplicity-corrected APOE4 interaction testing |
| [LGA-Net](https://github.com/Sobia7590/LGA-Net) | Dual-branch CNN-Transformer with a lesion-guided attention gate for diabetic retinopathy grading; QWK 0.905 on APTOS 2019 |
| [mri-report-generation-agent](https://github.com/Sobia7590/mri-report-generation-agent) | Agentic pipeline (Observe → Analyze → Report → Verify) for brain MRI report generation, built on Claude and the BraTS 2020 dataset |
